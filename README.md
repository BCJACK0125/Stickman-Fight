# Stickman-Fight

## 🥊 動態感的來源

* **骨架式姿勢系統**：角色由一組可插值的關節角度（髖、肩、肘、膝、整體旋轉）組成，動作之間自然過渡而非單純換圖。在地面時會自動將最低的腳貼齊地面，有效防止浮空或陷進地板。
* **命中定格（Hitstop）**：打中的瞬間雙方凍結 **6～13 幀**，此為格鬥遊戲打擊感最關鍵的要素。
* **視覺特效**：包含拳腳殘影弧線、衝刺時的分身殘影、鏡頭震動、命中火花、衝擊環以及傷害數字。
* **動態鏡頭**：鏡頭自動跟隨兩人中點。距離越近自動推近，最遠自動拉遠。擂台世界寬度為 **1240px**（寬於畫面），支援橫向捲動。

## ⚔️ 戰鬥機制

* **普通攻擊**：採取三段連段機制（直拳 → 迴旋踢 → 上勾拳）。最後一擊會將對手打飛至空中，收招後段按下一次攻擊即可接續連段。
* **特殊技能**：具備上下文分歧判定。
  * **地面施放**：衝刺拳（高傷害、高擊退）。
  * **空中施放**：斜下氣功彈。
  * **冷卻時間**：**3 秒**，血條下方設有進度條與秒數顯示。
* **拳頭對撞判定（CLASH）**：當雙方的 Hitbox 撞在一起時會自動彈開，且不扣除血量。
* **機動性系統**：支援二段跳、落地緩衝、撞牆反彈以及連段計數功能。
* **勝負規則**：採用 **99 秒**回合計時制。時間結束時由血量高者獲勝，同血量則判定為平手。

## ⚙️ 其他系統設計

* **介面視覺（UI）**：HP 條採用斜切造型，具備延遲的白色「掉血殘影」與低血量脈動警示。
* **音效表現**：全音效（揮空、命中、氣功、KO 鐘聲）皆使用 **WebAudio API** 即時合成，並可透過工具列自由開關。
* **輸入優化**：使用 `Set` 結構記錄按住的按鍵。攻擊判定僅觸發邊緣事件（Edge Trigger），確保多鍵同按絕不互卡；視窗失焦時會自動清空輸入，避免按鍵卡死。
* **效能流暢度**：採用固定 **1/60 秒**邏輯步進搭配 `requestAnimationFrame` 進行繪製，避免切換分頁回來時畫面暴衝。左下角同步顯示 **FPS 數據**。
